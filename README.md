# 微信机器人 v2.2.1

> ## ⚠️ 使用前必读
> - 本项目**仅供技术学习研究**。使用它**可能违反微信的服务协议，导致账号被限制或封禁**，风险由使用者自负。
> - 与腾讯 / 微信**没有任何关系**；不修改微信客户端、不注入内存，只使用系统公开能力（无障碍、输入法、截图）操作界面。
> - **严禁**用于发送垃圾信息、骚扰他人、诈骗、侵犯隐私等场景。
> - 完整条款见 **[免责声明](DISCLAIMER.md)** —— 不同意就不要用。

跑在 Android 手机 + DSH 容器里的微信群自动回复机器人（读屏 = 虚拟屏截图 + OCR，
回复 = DeepSeek 人设 / 关键词规则，不碰物理屏、不需要 root）。

## 最近版本变化（v2.2.1）

- **情绪系统**：5~95 心情值 + 按小时自然回落，影响语气与主动插话概率（`data/mood.json`）。
- **对人的态度记忆**：被夸 / 被凶 / 被叫会积累好感，只影响语气、不直接说出来（`data/relations.json`）。
- **随机碎话**：一天 3~5 次往目标群甩一句无厘头的话，句库可改；默认开启，
  `random_chatter.enabled: false` 可关。
- **识图门槛修复**：不再无脑读表情包、「糊图看不清」不再当聊天发出去。

细节见 [CHANGELOG.md](CHANGELOG.md)，玩法见 [功能介绍.md](功能介绍.md)。

## 机型兼容性：部分手机（如小米）可能需要 root / 插卡

本项目在 **OPPO / ColorOS（Android 14）** 真机上完整验证，**程序本身不需要 root**。
但它依赖「无线调试 → Shizuku → 虚拟屏守护 → 后台常驻」这一串系统能力，
不同厂商的限制差别很大：

| 机型 / 系统 | 可能需要的额外条件 |
|---|---|
| **小米 / 红米（MIUI / HyperOS）** | 「无线调试」通常要求**插入 SIM 卡**、登录小米账号，部分版本还有账号登录时长要求（常见 7 天）；如果这样仍拿不到 adb / Shizuku 授权，这类机型可能需要 **root 或解锁 Bootloader** 才能继续 |
| 华为 / 荣耀（HarmonyOS） | 后台与无障碍限制更严：一般要允许「后台弹出界面」「自启动」，并关闭省电优化；未做完整验证 |
| OPPO / ColorOS、一加、真我 | 本机验证通过；仍需允许浮窗与后台，并把省电策略设为「无限制」 |
| 其他 Android 11+ | 理论可用，前提是能开「无线调试」并授权 Shizuku |

**装之前先确认两件事**：你的手机能不能开「无线调试」、能不能授权 Shizuku。
两样都不行、又没有 root 的话，这套方案在你手机上跑不起来 —— 这是系统限制，不是装错了。

另外，**系统省电 / 后台清理会杀掉虚拟屏守护和浮窗**（表现为机器人突然不理人）：
把 DSH、Shizuku、微信都设成「不受限制」。

## 三行装起来

```sh
cd /sdcard/Download && unzip 微信机器人-v2.2.1.zip -d /sdcard/dsh/
cd /sdcard/dsh/微信机器人-v2.2.1
sh install.sh          # ⚠️ 必须 sh 开头，/sdcard 是 noexec
```

装完还有两步（连 adb + 起守护 + 填配置），照 **《快速开始.md》** 走一遍即可。

## 目录约定

- `payload/` —— 要安装的东西（程序 + 环境件 + OCR 运行时）
- `dsh安装包/` —— 附带的 DSH 安卓安装包 + 虚拟屏插件（**不是**微信机器人本体，是它依赖的环境件）
- `install.sh` —— 安装 / 升级程序（`sh install.sh --dry-run` 可先看它要做什么）
- 装完之后：程序在 `/sdcard/dsh/wechat-bot/app`、**你的数据在 `.../data`**、日志在 `.../logs`

## 架构一句话

```
微信（虚拟屏） → 截图 → RapidOCR → 消息/上下文
                                ↓
                     DeepSeek（人设 + 心情 + 关系 + 记忆）
                                ↓
         发送决策（配额/静默/防封号）→ 无键盘输入法 → 微信
```

全流程不碰物理屏、不需要 root：读屏靠虚拟屏截图 + OCR，发送靠系统输入法通道，
操作入口是容器里的 `phone` / `vscreen` 命令（走 adb 的 shell 权限）。
